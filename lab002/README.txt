## Вариант 9: билеты

Общий объём — количество билетов. В этом варианте единица размещения — пачка, вместимость — количество билетов в пачке.

Программа получает два целых неотрицательных числа и вычисляет:
- количество полностью заполненных пачек;
- остаток билетов;
- минимальное количество пачек для всего объёма.

Для последнего результата используется формула без условий:

python
(total + capacity - 1) // capacity


### Проверки

0, 10 → полных 0, остаток 0, всего 0.

20, 10 → полных 2, остаток 0, всего 2.

21, 10 → полных 2, остаток 1, всего 3.

### Ручной расчёт для 21 и 10

21 // 10 = 2
21 % 10 = 1
(21 + 10 - 1) // 10 = 3


Ответ: 2 полностью заполненные пачки, 1 билет в остатке, всего требуется 3 пачки.

## purchase.py

Расчёт стоимости покупки и сдачи. Например, 45 и 135 → стоимость 45, сдача 90; 45 и 100 → стоимость 45, сдача 55.

Форматирование числа не устраняет внутреннюю погрешность float: оно только меняет отображение уже вычисленного значения. Поэтому для этих простых денежных примеров используются целые числа.
