--------------------------------------------------------------------
3. ОТВЕТЫ НА ВОПРОСЫ ДЛЯ ЗАЩИТЫ
--------------------------------------------------------------------
1. Почему цикл в "positive_input.py" завершится?
   Цикл 'while True' является бесконечным, но внутри него стоит условный 
   оператор 'if num > 0: break'. Цикл гарантированно завершится, как только 
   пользователь введёт любое целое число строго больше нуля.

2. Почему range(a, b) не всегда соответствует условию задания №1?
   - Функция range(a, b) по умолчанию работает только в сторону возрастания 
     (с шагом +1) и не включает в себя правую границу 'b'.
   - Если передать 'a > b', то range(a, b) вернёт пустой диапазон. 
   - Чтобы выводить числа на убывание, необходимо явно передавать 
     отрицательный шаг: range(a, b - 1, -1).
