# Вариант 9 — Магазин настольных игр

## Задание

Программа `variant9.py` рассчитывает заказ из двух позиций:

1. Карточные игры
2. Головоломки

Используются только последовательные команды, базовые условия/циклы не требуются, а для хранения данных используются обычные переменные.

## Пример заказа для ручного расчёта

Название заказа: Подарок для друга  
Заказчик: Иван

 Первая позиция — Карточные игры
- Название: Уно
- Количество: 2
- Цена за единицу: 650 руб
- Стоимость: 2 × 650 = 1300 руб

### Вторая позиция — Головоломки
- Название: Кубик Рубика
- Количество: 3
- Цена за единицу: 450 руб.
- Стоимость: 3 × 450 = 1350 руб

### Доставка и оплата
- Доставка:300 руб
- Внесённая сумма:3500 руб

### Ожидаемые результаты

Стоимость товаров:

1300 + 1350 = 2650 руб

Общая сумма с доставкой:

2650 + 300 = 2950 руб

Общее количество единиц:

2 + 3 = 5 шт.

Сдача:

3500 - 2950 = 550 руб
